# Jyoti

A simple and elegant static web page project created using HTML and CSS. This project showcases clean structure, basic styling, and image integration—ideal for learning or demonstrating foundational frontend skills.

## 🌐 Live Preview

To preview the project locally, open the `index.html` file in any modern web browser.

## 📁 Project Structure

```
Jyoti/
├── index.html         # Main HTML file
├── style.css          # External CSS for styling
└── images/            # Folder containing all image assets
```

## 🚀 Getting Started

To set up and run this project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/Priyalsoni02/Jyoti.git
   ```

2. Navigate to the project directory:
   ```bash
   cd Jyoti
   ```

3. Open the `index.html` file with your browser:
   - On Windows: double-click the file
   - On macOS/Linux: `open index.html` or `xdg-open index.html`

## 🛠️ Technologies Used

- **HTML5** – Structure of the webpage
- **CSS3** – Styling and layout

- Simple and responsive design
- Clean and readable code
- Lightweight and fast-loading
